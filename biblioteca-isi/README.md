# Biblioteca visual del modelo ISI en Chile

**52 fichas documentales de fotografías y colecciones** de la Biblioteca Nacional Digital de Chile, con explicaciones educativas y enlace a cada fuente.

> [Abrir la biblioteca interactiva (archivo HTML)](./index.html) · Para verla como web, descargar el HTML y abrirlo en el navegador. Las imágenes se sirven desde los archivos históricos originales; algunos servidores pueden impedir la vista previa.

El modelo de **Industrialización por Sustitución de Importaciones (ISI)** buscó producir dentro de Chile bienes antes importados. La CORFO (1939) promovió energía, siderurgia y otras industrias estratégicas. Algunas fotografías muestran el **legado posterior a 1973** y están identificadas como tales.
